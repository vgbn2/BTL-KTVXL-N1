# MPU6050 6-Axis MotionTracking Module Reference

## 1. Specifications & Hardware
- **Sensors:** 3-axis Accelerometer (±2g, ±4g, ±8g, ±16g) + 3-axis Gyroscope (±250, ±500, ±1000, ±2000 °/s).
- **Interface:** I2C (Standard Mode 100 kHz, Fast Mode 400 kHz).
- **Default I2C Address:**
  - `0x68` (AD0 pin = GND / LOW)
  - `0x69` (AD0 pin = 3.3V / HIGH)
- **Power:** 3.3V - 5V via onboard LDO on GY-521 breakout board.

## 2. Register Map Key Summary
| Register | Hex | Function | Description |
| :--- | :--- | :--- | :--- |
| `SMPLRT_DIV` | `0x19` | Sample Rate Divider | Sample Rate = Gyroscope Output Rate / (1 + SMPLRT_DIV) |
| `CONFIG` | `0x1A` | DLPF Configuration | Digital Low Pass Filter config |
| `GYRO_CONFIG` | `0x1B` | Gyro Full Scale | Set ±250°/s (`0x00`), ±500°/s (`0x08`), etc. |
| `ACCEL_CONFIG` | `0x1C` | Accel Full Scale | Set ±2g (`0x00`), ±4g (`0x08`), etc. |
| `ACCEL_XOUT_H` | `0x3B` | Accel Data Start | 6 consecutive bytes: X, Y, Z raw values |
| `TEMP_OUT_H` | `0x41` | Temperature Start| 2 bytes: Temperature |
| `GYRO_XOUT_H` | `0x43` | Gyro Data Start | 6 consecutive bytes: X, Y, Z raw values |
| `PWR_MGMT_1` | `0x6B` | Power Management 1 | Set `0x00` to wake up chip from sleep mode |
| `WHO_AM_I` | `0x75` | Identity Check | Returns `0x68` |

## 3. Complementary Filter Formula
$$\theta_{\text{angle}}(t) = \alpha \cdot \left(\theta_{\text{angle}}(t - \Delta t) + \omega_{\text{gyro}} \cdot \Delta t\right) + (1 - \alpha) \cdot \theta_{\text{accel}}$$

Where:
- $\alpha \approx 0.96 - 0.98$
- $\Delta t = 0.01\text{s}$ (100 Hz fixed loop via STM32 Timer)
- $\theta_{\text{accel}} = \text{atan2}(a_y, a_z) \cdot \frac{180}{\pi}$
