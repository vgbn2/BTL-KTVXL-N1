### 1.3 Dual-MPU6050 Hardware Bus Anchoring on Single I2C1

The project utilizes two independent MPU-6050 sensors on the same physical I2C1 bus (`PB6` SCL, `PB7` SDA) without multiplexer hardware:
- **MPU 1 (Primary / Reference IMU):** `AD0` pin soldered to **GND** $\rightarrow$ 7-bit Address = `0x68` (Write: `0xD0`, Read: `0xD1`).
- **MPU 2 (Secondary / Redundancy IMU):** `AD0` pin soldered to **3.3V** $\rightarrow$ 7-bit Address = `0x69` (Write: `0xD2`, Read: `0xD3`).

## 4. Deep-Dive Extraction of Key Functional Registers

### 4.1 Sample Rate Calculation & SMPLRT_DIV (Section 4.2, p. 11)

The internal sensor sample rate is configured via Register 25 (`0x19`):

$$\text{Sample Rate} = \frac{\text{Gyroscope Output Rate}}{1 + \text{SMPLRT\_DIV}}$$

- When DLPF is **disabled** (`DLPF_CFG = 0` or `7` in Register 26): Gyroscope Output Rate = **$8\text{ kHz}$**.
- When DLPF is **enabled** (`DLPF_CFG = 1` through `6`): Gyroscope Output Rate = **$1\text{ kHz}$**.

**Project Timing Anchor:**  
With DLPF configured to `0x03` ($1\text{ kHz}$ base rate):
- Setting `SMPLRT_DIV = 0x09` ($9_{\text{dec}}$) yields:
  $$\text{Sample Rate} = \frac{1000\text{ Hz}}{1 + 9} = 100\text{ Hz}\quad (10.0\text{ ms period})$$
  This precisely synchronizes with the system timer interrupt defined in `docs/QUY_TAC_CODE_NHOM_MPU6050.md` (`IMU_SAMPLE_RATE_HZ = 100`, $dt = 0.01\text{ s}$).
- Setting `SMPLRT_DIV = 0x19` ($25_{\text{dec}}$) yields:
  $$\text{Sample Rate} = \frac{1000\text{ Hz}}{1 + 25} \approx 38.46\text{ Hz}$$

### 4.2 Digital Low Pass Filter (DLPF_CFG) Mechanics (Section 4.3, p. 13)

Register 26 (`0x1A` / `CONFIG`) bits `[2:0]` configure the on-chip analog-to-digital converter (ADC) digital filter pipeline for both Accelerometer and Gyroscope signals:

| DLPF_CFG | Accelerometer Bandwidth (Hz) | Accelerometer Delay (ms) | Gyroscope Bandwidth (Hz) | Gyroscope Delay (ms) | Fs (kHz) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **`0`** | 260 | 0.0 | 256 | 0.98 | 8 |
| **`1`** | 184 | 2.0 | 188 | 1.9 | 1 |
| **`2`** | 94 | 3.0 | 98 | 2.8 | 1 |
| **`3`** | **44** | **4.9** | **42** | **4.8** | **1** |
| **`4`** | 21 | 8.5 | 20 | 8.3 | 1 |
| **`5`** | 10 | 13.8 | 10 | 13.4 | 1 |
| **`6`** | 5 | 19.0 | 5 | 18.6 | 1 |
| **`7`** | RESERVED | RESERVED | RESERVED | RESERVED | 8 |

**Design Choice (`DLPF_CFG = 0x03`):**  
Bandwidth of $44\text{ Hz}$ on accelerometer and $42\text{ Hz}$ on gyroscope attenuates high-frequency motor vibration and chassis resonance (>50 Hz) while introducing only $\approx 4.8\text{ ms}$ of group delay, well within our $10\text{ ms}$ ($100\text{ Hz}$) control loop deadline.

### 4.4 Shadow Registers & Atomic 14-Byte Burst Read Mechanism (Section 4.18, p. 30)

A critical architectural feature detailed in Section 4.18 of `RM-MPU-6000A` is the **User-Facing Read Buffer** (shadow register architecture):

```text
+---------------------------------------------------------------------------------+
|                       INTERNAL SENSOR SAMPLE PIPELINE                            |
|  [ADC / DLPF Engine] ---> Updates Internal Holding Registers @ Sample Rate (1kHz) |
+---------------------------------------------------------------------------------+
                                        |
                 Updated only when I2C bus is IDLE or at START condition
                                        v
+---------------------------------------------------------------------------------+
|                       USER-FACING SHADOW REGISTERS                               |
|  0x3B (ACCEL_X_H) .. 0x40 (ACCEL_Z_L) | 0x41..0x42 (TEMP) | 0x43..0x48 (GYRO_Z_L)|
+---------------------------------------------------------------------------------+
                                        ^
                                        | Read atomically via I2C Auto-Increment
+---------------------------------------------------------------------------------+
| STM32 Master: Single 14-Byte Burst Read Transaction starting at Reg 0x3B         |
+---------------------------------------------------------------------------------+
```

**Hardware Invariant:**  
> *"The most recent record is stored in a set of registers which are user-facing read registers. These registers are updated with the value of the internal registers when the serial interface is idle. If the user reads an accelerometer data register and that data register is subsequently updated with new data, the read value will not be affected."* (RM-MPU-6000A Section 4.18)

**Why Individual Byte Reads Fail:**  
If a driver reads high byte `ACCEL_XOUT_H` and low byte `ACCEL_XOUT_L` in separate I2C transactions, an internal ADC sample clock edge occurring between the two reads can cause MSB/LSB tearing (e.g., transition from `0x00FF` to `0x0100` read as `0x0000` or `0x01FF`).  
**Driver Implementation Rule:**  
Always issue an atomic 14-byte sequential burst read starting at register `0x3B`:
```c
uint8_t raw[14];
HAL_I2C_Mem_Read(&hi2c1, (dev_addr << 1), 0x3B, 1, raw, 14, 50);
```

### 4.5 Temperature Sensor Formula & Characteristics (Section 4.19, p. 31)

Registers 65 and 66 (`0x41` and `0x42`) provide a 16-bit signed measurement of silicon die temperature.

#### Transfer Function:

$$\text{Temperature in } ^\circ\text{C} = \frac{\text{TEMP\_OUT}}{340} + 36.53$$

- **Zero-Reading Point:** $\text{TEMP\_OUT} = 0 \implies T = 36.53^\circ\text{C}$.
- **Sensitivity:** $340\text{ LSB} / ^\circ\text{C}$.
- **Linear Range:** $-40^\circ\text{C} \text{ to } +85^\circ\text{C}$.

### 4.6 Power Management 1 & Clock Selection (Section 4.30, p. 41)

Register 107 (`0x6B` / `PWR_MGMT_1`):

| Bit | Bit Name | Reset | Description |
| :---: | :--- | :---: | :--- |
| **7** | `DEVICE_RESET` | 0 | Writing `1` resets all internal registers to default. Self-clearing bit. |
| **6** | `SLEEP` | **1** | Silicon boots into low-power sleep mode by default (`0x40`). Must write `0` to wake! |
| **5** | `CYCLE` | 0 | Cycle mode: sleeps and wakes up at rate set by `LP_WAKE_CTRL`. |
| **4** | Reserved | 0 | Reserved. |
| **3** | `TEMP_DIS` | 0 | Writing `1` disables the internal temperature sensor. |
| **[2:0]**| `CLKSEL[2:0]` | 000 | Clock source selection (see table below). |

#### Clock Source Selection Table (`CLKSEL`):

| CLKSEL | Clock Source Description | Recommended Usage |
| :---: | :--- | :--- |
| **`0`** | Internal 8 MHz oscillator | Default at boot; prone to thermal drift ($\pm 5\%$). |
| **`1`** | **PLL with X-axis gyroscope reference** | **Highly Recommended:** Ultra-stable crystal-derived gyro clock. |
| **`2`** | PLL with Y-axis gyroscope reference | Stable crystal reference. |
| **`3`** | PLL with Z-axis gyroscope reference | Stable crystal reference. |
| **`4`** | PLL with external 32.768 kHz reference | Requires external clock source on CLKIN pin. |
| **`5`** | PLL with external 19.2 MHz reference | Requires external clock source on CLKIN pin. |
| **`6`** | Reserved | Do not use. |
| **`7`** | Stops clock generator (Reset state) | Timing generator held in reset. |

**Bring-Up Invariant:**  
Always write `0x01` to `PWR_MGMT_1` during initialization: wakes the chip from sleep (`SLEEP=0`) and locks PLL to the X-axis gyroscope oscillator (`CLKSEL=1`).

### 4.7 Power Management 2 & Low-Power Wake Control (Section 4.31, p. 43)

Register 108 (`0x6C` / `PWR_MGMT_2`):
- `LP_WAKE_CTRL[7:6]`: Controls accelerometer wake-up frequency in low-power cycle mode:
  - `00`: $1.25\text{ Hz}$
  - `01`: $5\text{ Hz}$
  - `10`: $20\text{ Hz}$
  - `11`: $40\text{ Hz}$
- `STBY_XA, STBY_YA, STBY_ZA`: Individual standby disable for accelerometer axes.
- `STBY_XG, STBY_YG, STBY_ZG`: Individual standby disable for gyroscope axes.

---

### 4.8 Identity Verification Register (WHO_AM_I, Section 4.34, p. 46)

Register 117 (`0x75` / `WHO_AM_I`):
- Bits `[6:1]` hold the upper 6 bits of the 7-bit default I2C address: `0b110100` (`0x68`).
- Bits `[7]` and `[0]` are reserved and read as `0`.
- Expected return on authentic MPU-6050: **`0x68`**.
- MPU-6500 variant return: **`0x70`**.
- InvenSense clone/variant return: **`0x72`**.

## 5. Dual-Sensor I2C Communication Sequences

### 5.1 Device Wake-Up & Configuration Sequence

```text
Master: [START] -> [ADDR+W (0xD0/0xD2)] -> [ACK] -> [0x6B (PWR_MGMT_1)] -> [ACK] -> [0x80 (RESET)] -> [ACK] -> [STOP]
(Wait 100 ms for analog LDO & charge pump stabilization)
```

## 6. Mathematical Tilt Estimation & Complementary Filter Pipeline

### 6.1 Theoretical Basis (MEMS Accelerometer vs Gyroscope)

- **Accelerometer:** Measures the net acceleration vector $\vec{a} = \vec{a}_{\text{dynamic}} - \vec{g}$. In quasi-static conditions ($\vec{a}_{\text{dynamic}} \approx 0$), it provides an absolute, drift-free gravity reference vector, but is highly sensitive to external mechanical vibrations and shock noise.
- **Gyroscope:** Measures body angular rotation rate $\vec{\omega}$. Integrating $\vec{\omega} \cdot \Delta t$ provides smooth, instantaneous high-frequency angle changes immune to linear vibrations, but accumulates DC sensor bias into unbounded integration drift over time.

### 6.2 Accelerometer Angle Calculations (Team Standard: TV3 / TV1)

In accordance with Section 4 of `docs/QUY_TAC_CODE_NHOM_MPU6050.md`:

#### Roll ($\theta_{\text{roll}}$, rotation around X-axis):
$$\text{acc\_roll\_deg} = \text{atan2f}(a_y, a_z) \times \frac{180.0}{\pi}$$

#### Pitch ($\theta_{\text{pitch}}$, rotation around Y-axis):
$$\text{acc\_pitch\_deg} = \text{atan2f}\left(-a_x, \sqrt{a_y^2 + a_z^2}\right) \times \frac{180.0}{\pi}$$

### 6.3 Discrete-Time Complementary Filter Equation

Combining the high-pass filtered gyro integration with the low-pass filtered accelerometer reference:

$$\theta_{\text{roll}}(k) = \alpha \cdot \left(\theta_{\text{roll}}(k-1) + g_x \cdot \Delta t\right) + (1.0 - \alpha) \cdot \text{acc\_roll\_deg}(k)$$

$$\theta_{\text{pitch}}(k) = \alpha \cdot \left(\theta_{\text{pitch}}(k-1) + g_y \cdot \Delta t\right) + (1.0 - \alpha) \cdot \text{acc\_pitch\_deg}(k)$$

- $\Delta t = 0.01\text{ s}$ ($100\text{ Hz}$ sample period from STM32 Timer).
- $\alpha = 0.98$ (Default filter constant, tunable via UART `SET_FILTER_ALPHA:0.98` between $0.50$ and $0.999$).
- Cutoff frequency:
  $$f_c = \frac{1 - \alpha}{2 \pi \alpha \Delta t} = \frac{1 - 0.98}{2 \pi \times 0.98 \times 0.01} \approx 0.325\text{ Hz}$$
